# CV Online — Sabrina Eka Cahyani

Website CV satu halaman yang responsif, dibuat menggunakan HTML, CSS, dan JavaScript biasa. Dapat dipublikasikan gratis melalui GitHub Pages (`username.github.io`).

## Isi folder

- `index.html` — struktur halaman dan konten CV.
- `style.css` — tampilan, layout responsif, dan gaya cetak.
- `script.js` — menu navigasi untuk ponsel, tahun otomatis, dan tombol cetak CV.

## Menjalankan secara lokal

1. Unduh atau ekstrak folder proyek ini.
2. Buka `index.html` di browser.
3. Tidak membutuhkan instalasi package atau proses build.

Google Fonts digunakan untuk tipografi. Jika tidak ada koneksi internet, browser akan menggunakan font cadangan.

## Publikasi di GitHub Pages

1. Masuk ke [GitHub](https://github.com/) dan buat repository baru.
2. Unggah `index.html`, `style.css`, `script.js`, dan `README.md` ke root repository (folder utama).
3. Buka **Settings → Pages** pada repository.
4. Di bagian **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, lalu klik **Save**.
6. Tunggu proses publikasi selesai. GitHub akan menampilkan alamat website di halaman Pages.

### Alamat website

- Jika nama repository adalah `username.github.io`, alamatnya: `https://username.github.io/`
- Jika memakai nama repository lain, misalnya `cv-sabrina`, alamatnya: `https://username.github.io/cv-sabrina/`

Ganti `username` dengan nama pengguna GitHub Anda.

## Mengubah konten

Buka `index.html` dengan editor teks atau Visual Studio Code, lalu edit bagian yang diperlukan. Warna, ukuran, jarak, dan layout dapat diubah di `style.css`.

## Catatan privasi

Website yang dipublikasikan melalui GitHub Pages bersifat publik. Periksa kembali apakah Anda nyaman menampilkan nomor telepon, email, dan domisili sebelum memublikasikannya.
